# Implementation Roadmap

This repository is intentionally modular. A topic listed here is planned, not necessarily implemented in the current starter release.

## Implemented
- [x] Generic dynamic array
- [x] Singly linked list
- [x] Array-backed stack
- [x] Circular array queue
- [x] Linked stack and linked queue
- [x] Doubly linked list
- [x] Chained hash map
- [x] Binary search tree (unbalanced)
- [x] Binary min-heap
- [x] Trie
- [x] Adjacency-list graph with BFS and DFS
- [x] Binary search
- [x] Insertion sort
- [x] Merge sort
- [x] Quicksort
- [x] Linear search
- [x] Palindrome check
- [x] Fibonacci dynamic-programming examples
- [x] JUnit tests for the implemented core

## Next data structures
- [ ] Doubly and circular linked lists
- [ ] Linked-list stack and queue
- [ ] Deque
- [ ] Hash map and hash set
- [ ] Binary search tree and AVL tree
- [ ] Binary heap / priority queue
- [ ] Trie
- [ ] Disjoint-set union
- [ ] Graph representations
- [ ] Fenwick tree and segment tree

## Next algorithms
- [ ] Selection, bubble, shell, heap, quick, counting, radix, and bucket sort
- [ ] Linear search and interpolation search
- [ ] Two pointers, sliding window, prefix sums
- [ ] String matching: KMP, Rabin–Karp, Z algorithm
- [ ] Recursion and backtracking
- [ ] Greedy algorithms
- [ ] Dynamic programming patterns
- [ ] Graph traversal, topological sort, shortest paths, MST
- [ ] Bit manipulation and number theory

## Definition of done
- Public API has Javadoc.
- Invalid inputs are handled consistently.
- Edge cases have unit tests.
- Complexity and trade-offs are documented.
- Example code compiles and runs.
